# 0.1.x 维护与问题分级

`0.1.x` 进入稳定维护阶段。维护目标是修复可复现问题，同时保持本地优先、原文件只读、Web-only、风险预览和人工确认等正式版约束。

## 受理证据

有效报告至少应包含正式版版本号、运行环境、最小步骤、预期结果、实际结果和复现频率。文档兼容性问题还应说明文件类型、生成软件、水印结构、页面结构和是否存在文字层、链接或表单。

优先接受生成夹具或生成脚本。真实用户文件、私人分享链接、凭据、个人信息和本地路径不能进入公开 Issue、Git 历史、CI Artifact 或发行物。无法公开最小化的报告只能作为待补证据问题，不能直接形成公开测试夹具。

## 严重程度

| 等级 | 判定 | 处理要求 |
|---|---|---|
| Critical | 可导致远程代码执行、任意文件读写、批量敏感数据泄露或发行供应链失陷 | 停止相关发布，使用私密安全报告处理 |
| High | 能稳定破坏原文件保护、绕过人工确认、访问非预期网络或泄露单个敏感文件 | 阻断补丁发布，修复并增加回归证据 |
| Medium | 处理结果错误、文档明显损坏、支持格式在常见环境稳定失败，但有安全的替代流程 | 纳入最近补丁候选并添加最小夹具 |
| Low | 小范围显示、提示、文档或罕见兼容性问题 | 按影响和可复现性排序 |

严重程度只描述影响，不能代替复现证据。无法复现的问题标记为需要信息；确认属于环境或不支持结构的问题，应更新边界文档。

## 补丁候选条件

补丁候选只包含已经关联到复现证据和回归检查的修复。准备发布前必须确认：

1. 没有未解决的可复现 Critical 或 High 问题；
2. 原始输入仍保持只读，输出仍写入独立文件；
3. Web、API、CLI 和数据迁移行为与兼容约定一致；
4. VLM 仍默认关闭、不自动下载权重，建议仍需人工复核；
5. Linux、macOS、Windows wheel/CLI 证据和聚合门禁通过；
6. 全量后端检查、Vue 类型检查和生产构建通过；
7. 干净安装、生产 Web 路由、浏览器控制台和安全响应头通过；
8. 两次独立构建一致，最终资产通过许可证、归档安全、摘要和隐私扫描；
9. 从 GitHub Release 回下载的资产与本地审计字节一致。

补丁发布不自动上传 PyPI，不移动已有标签，也不替换已经发布的资产。

## 依赖监控

GitHub Dependabot 每周一按北京时间依次检查 Python、前端 npm 和 GitHub Actions 依赖。漏洞警报和自动安全更新在仓库级启用；版本更新只形成待审 Pull Request，不会自动合并或发布。

每个依赖更新仍需通过现有 CI。涉及运行时依赖时，还要重新生成第三方依赖清单与 SPDX SBOM，并复核许可证、发行包体积、干净安装和隐私边界。模型依赖及权重继续保留为显式可选能力，不能通过自动更新进入默认发行物。

常规 Dependabot 更新限制在当前主版本内；主版本升级需要单独设计、兼容性评估和明确计划。Pull Request 的依赖差异门禁会拒绝新增 High 或 Critical 已知漏洞，并且不会向 PR 自动发布评论。依赖清单或 SBOM 未同步时，现有发布门禁会直接失败。

每次推送到 `main` 或创建 Pull Request 时，持续集成会独立执行 Python Ruff、全量后端测试，以及 Vue 类型检查、生产构建和 npm 高危漏洞审计。覆盖率采集保留在本地 `make check`，避免在共享 CI runner 上为每个隔离工作进程注入 instrumentation 并造成启动超时。发行证据门禁继续单独验证三平台 wheel/CLI、依赖清单、SBOM 和聚合证据。

`main` 分支要求合并分支先同步最新主线，并通过 `backend`、`frontend`、`dependency-review`、`aggregate-evidence`、`Analyze (javascript-typescript)` 和 `Analyze (python)`。分支禁止强制推送和删除，Pull Request 讨论必须解决后才能合并。仓库按单人维护模式运行，不要求外部审批人数；维护者仍需根据本文件逐项审核证据。

CodeQL 对每个 Pull Request、`main` 推送和每周定时任务分别分析 Python 与 JavaScript/TypeScript。分析使用解释型语言的无构建模式，不读取用户运行数据、私有测试材料或本机工作目录；发现的告警按安全策略分级处理。

所有第三方 GitHub Actions 都固定到完整提交 SHA，版本注释放在引用旁供人工审核和 Dependabot 更新。`backend` 必需检查会拒绝新增的浮动标签或分支引用。
